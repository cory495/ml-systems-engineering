# Designing Data-Intensive Applications

## Overview
A foundational systems book that explains how modern large-scale data systems are built, focusing on scalability, reliability, and maintainability. It bridges theory and real-world distributed system design.

---

## What is this book about?
This book explains the core principles behind building systems that handle large-scale data.

It focuses on:
- How data is stored and retrieved efficiently
- How systems scale across machines
- How failures are handled in distributed environments
- Trade-offs between consistency, availability, and latency

It is essentially a blueprint for modern backend and distributed systems design.

## Core concepts
- Trade-offs between consistency, availability, and partition tolerance (CAP)
- Log-structured storage systems
- Indexing strategies (B-trees vs LSM trees)
- Replication strategies (single-leader, multi-leader, leaderless)
- Partitioning (sharding) strategies
- Distributed consensus (Raft, Paxos concepts)
- Stream vs batch processing paradigms
- Fault tolerance in distributed systems
