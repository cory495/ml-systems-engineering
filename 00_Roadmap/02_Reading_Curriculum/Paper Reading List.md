# Reading Strategy

For each paper:

## First Pass (15–20 min)

- Problem
    
- Motivation
    
- Main idea
    
- Results
    

---

## Second Pass (45–60 min)

Understand:

- Architecture
    
- Equations
    
- Figures
    
- Training setup
    

---

## Third Pass (Optional)

Reproduce:

- Key experiments
    
- Small implementation
    
- Ablation analysis
    

---

# Deliverables

For every paper:

- One Obsidian note
    
- One-page summary
